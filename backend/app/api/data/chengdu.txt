# 成都旅游必玩攻略
## 一、城市概览定位
成都是“天府之国”的中心，以**大熊猫、三国文化、休闲市井与火辣美食**为核心名片。城市气质慵懒且包容，“少不入蜀”是其最佳注脚。最佳旅游季节为秋季（9-11月）和春季（3-6月），气候舒适。建议游玩时长3-5天。成都旅游核心优势在于景点集中、交通便捷，且免预约景点较多，适合随性漫游。

## 三、行程规划建议
**四日经典线（首次到访首选）**
- **Day1（熊猫与市井日）**：早上7:30大熊猫基地 → 下午宽窄巷子 → 傍晚人民公园鹤鸣茶社 → 夜游春熙路/IFS大熊猫。
- **Day2（寻古与三国日）**：上午杜甫草堂 → 下午武侯祠 → 傍晚锦里看夜景。
- **Day3（古蜀探秘日）**：全天广汉三星堆博物馆（半天）+ 下午返程成都吃火锅。
- **Day4（山水休闲日）**：犀浦城际铁路至都江堰 → 下午青城山前山 → 晚返成都。
**关键动线逻辑**：市区景点基本在地铁2、3、4号线串联，步行+地铁即可高效完成；周边短途（三星堆、都江堰）均以成都东站和犀浦站为枢纽，当日往返无压力。住宿必须选二环内（春熙路、宽窄巷子、武侯祠片区），成都夜生活丰富，市中心交通便利性极高。
## 四、美食与住宿
**必吃美食**：成都火锅（牛油重，微辣是最后的妥协，推荐蜀大侠、小龙坎、电台巷）、串串香（结子、牛肉、折耳根必点）、钵钵鸡（冷吃串串，红油藤椒双拼）、麻婆豆腐、回锅肉、甜水面、钟水饺、兔头（老妈兔头）、蹄花汤。
**避坑提示**：锦里、宽窄巷子内的小吃（三大炮、伤心凉粉）多为流水线产品，价格贵且不正宗；吃火锅不要迷信网红店排长队，街边社区老火锅（如九宫格、无名火锅）味道更地道且性价比高；肠胃不佳者吃辣需量力而行，备好肠胃药。
**住宿建议**：
- **购物与夜生活首选**：春熙路/太古里/天府广场周边（地铁1/2/3号线交汇，极度繁华，去哪都近）。
- **文化氛围与慢生活**：宽窄巷子/人民公园/武侯祠周边（老成都底蕴，环境安静，适合散步）。
- **中转或性价比**：成都东站周边（高铁通勤方便，酒店性价比高，地铁2号线直达市区）。
## 五、实用贴士与常见坑
**交通**：成都双流机场（距市区近，地铁10号线直达）和天府机场（距市区远，地铁18号线直达，打车需1小时以上）；市区地铁网络发达，支付宝“出行”或下载“天府通”APP均可乘车；出租车/网约车易在早晚高峰（17:00-19:00）堵车，建议错峰出行。
**核心避坑清单**：
1. **熊猫基地黄牛票**：官方渠道票充足时黄牛加价售卖均为骗局；基地门票实名制，无法转赠。
2. **采耳陷阱**：人民公园、宽窄巷子的非正规采耳师傅常以“免费试一下”开头，随后收取高价；务必去鹤鸣茶社等正规门店明码标价采耳。
3. **变脸表演捆绑消费**：某些酒馆的川剧变脸表演看似免费，实则最低消费极高或需高额门票，看戏前问清收费标准。
4. **锦里小吃街**：溢价高且味道不正宗，建议仅逛街拍照，吃东西出巷子找老店。
**特殊人群提示**：
- **亲子家庭**：除熊猫基地外，成都浩海海洋公园（双流）、欢乐谷、融创雪世界均为优质亲子选项；带小孩尽量避免去太古里等拥挤商业区。
- **老年游客**：青城山步道较陡，建议坐索道；都江堰水利工程需走步道，建议穿防滑鞋；市区多安排茶社、公园休息。
**气候与穿搭**：成都属亚热带季风气候，全年多云多雾，少日照。夏季（6-8月）闷热潮湿，体感温度极高，需频繁冲凉；冬季（12-2月）阴冷少雪，无集中供暖，室内需穿羽绒服；春秋两季宜人但易下阵雨，出门需带伞。盆地气候使得紫外线较弱，无需重度防晒，但防潮防雨是重点。
