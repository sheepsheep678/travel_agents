# 杭州旅游必玩攻略
## 一、城市概览定位
杭州是“人间天堂”，以**西湖山水、南宋都城遗韵、千年茶文化与江南水乡风貌**为核心名片。核心体验在于“淡妆浓抹总相宜”的湖光山色与禅意古刹。最佳旅游季节为春季（3-5月，春花烂漫）与秋季（9-11月，满城桂花香）。建议游玩时长3-5天。杭州是最早实行景点免费的城市之一，西湖大门票免费，但灵隐寺等热门景点需提前预约，周末与节假日交通管制严格。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（西湖深度日）**：早上断桥-白堤-孤山 → 下午苏堤漫步-乘船游三潭印月 → 傍晚雷峰塔看夕阳 → 晚上河坊街觅食。
- **Day2（禅茶寻幽日）**：早上灵隐寺与飞来峰 → 下午法喜寺（网红寺庙）或龙井村品茶 → 傍晚钱江新城看灯光秀。
- **Day3（湿地或主题日）**：上午西溪湿地坐摇橹船 → 下午宋城看《千古情》演出。
**关键动线逻辑**：西湖是绝对中心，将其分为北线（断桥-孤山）、西线（岳庙-曲院风荷）、南线（雷峰塔-太子湾）分段游玩，切忌一天步行绕湖一圈（超20公里，极度劳累）。住宿首选西湖周边或地铁1号线沿线，杭州景区周末极度拥堵，务必地铁出行。
## 四、美食与住宿
**必吃美食**：杭帮菜代表（西湖醋鱼口味偏酸甜，外地人评价两极分化、东坡肉、龙井虾仁、叫花鸡），片儿川（面条筋道、雪菜笋肉浇头）、葱包桧、定胜糕、西湖藕粉。知名餐饮有楼外楼（游客打卡，价高）、知味观（小吃为主）、新白鹿与外婆家（高性价比本地连锁）。
**避坑提示**：景区周边“野生西湖龙井”多为假货，正宗明前茶价格不菲；河坊街小吃同质化严重，不如去附近大马弄或吃正规杭帮菜馆；西湖醋鱼若不喜欢酸甜口味慎点。
**住宿建议**：
- **观景与便利首选**：西湖/湖滨商圈（地铁1号线龙翔桥站，出门见西湖，购物餐饮极度发达）。
- **交通枢纽与性价比**：钱江新城/武林广场周边（地铁1/2/4号线交汇，酒店较新，去西湖2-3站）。
- **度假休闲**：西溪湿地周边或千岛湖（适合泡酒店、远离喧嚣）。
## 五、实用贴士与常见坑
**交通**：萧山机场地铁1号线、7号线、19号线均可直达市区（19号线快速直达火车东站及西湖区）；杭州东站为高铁主力枢纽，地铁1/4/6号线换乘；市内出行首选地铁+共享单车，西湖景区周末单双号限行，打车常堵在路上。
**核心避坑清单**：
1. **出租车/滴滴司机带客买茶/买丝**：从机场、车站打车去景区，司机常以“今天龙井村有茶农自家茶出售”“丝绸博物馆有打折展销”为由绕路带去消费，拿高额回扣。务必坚决拒绝，去正规门店购买。
2. **西湖周边“黑导游”**：断桥、雷峰塔附近有大妈提供“带你走小路免门票”“便宜坐船”服务，实为带去周边珍珠店、龙井茶庄消费，切勿跟随。
3. **假西湖龙井茶**：路边“现炒现卖”多为外地绿茶染色或冒充，真龙井需认准防伪标，且价格不会低于千元一斤（明前茶）。
4. **节假日拥堵陷阱**：周末与节假日西湖周边单行、限行，打车寸步难行，务必使用公共出行或共享单车。
**特殊人群提示**：
- **亲子家庭**：除西湖外，杭州极地海洋公园、烂苹果乐园、宋城适合亲子；西湖边可租脚踏船，但需注意防晒。
- **老年游客**：西湖游船有平层客舱无需攀爬；灵隐寺飞来峰有较多台阶，注意防滑；苏堤白堤无树荫遮挡，夏季需打伞防暑。
**气候与穿搭**：杭州属亚热带季风气候，夏季（6-8月）闷热多雨，梅雨季极度潮湿，需常备雨具与换洗衣物；冬季湿冷无集中供暖，需穿羽绒服；春秋两季最为舒适，但早晚温差大，西湖边风大需带薄外套。全年需备防晒与雨具，建议穿舒适运动鞋以应对长距离步行。
