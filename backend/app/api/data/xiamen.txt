# 厦门旅游必玩攻略
## 一、城市概览定位
厦门是“海上花园”，核心看点为**世界文化遗产鼓浪屿、闽南侨乡建筑、最美海岸线与文艺清新的市井气息**。城市气质浪漫且慵懒，是国内Citywalk与海边度假的顶流目的地。最佳旅游季节为春季（3-5月）与秋季（10-12月），气候宜人且避开了台风季。建议游玩时长3-4天。厦门本岛景点极度集中，BRT与地铁串联核心区，但前往鼓浪屿必须提前实名抢票，无票无法登岛。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（琴岛慢游日）**：早班船登鼓浪屿 → 游览最美转角、日光岩、菽庄花园 → 傍晚离岛至中山路步行街吃晚餐。
- **Day2（山海文艺日）**：早上南普陀寺 → 上午厦门大学（如约到）→ 下午植物园看雨林雾森与多肉 → 傍晚沙坡尾看日落。
- **Day3（海岸线日）**：早上黄厝海滩看日出 → 上午环岛路骑行 → 下午曾厝垵逛吃 → 晚上乘地铁1号线去集美学村看夜景。
**关键动线逻辑**：厦门岛分为本岛与鼓浪屿，鼓浪屿必须单独安排一整天且需早登岛（9点前人流较少）。本岛景点集中在思明区（南普陀、厦大、沙坡尾、植物园），相互间距离极近，步行或共享单车即可。住宿优先选中山路或厦大/沙坡尾周边，兼顾老城区美食与看海便利。
## 四、美食与住宿
**必吃美食**：沙茶面（乌糖、四里、月华，汤头浓郁配料自选）、海蛎煎（地瓜粉与海蛎鸡蛋，蘸甜辣酱）、土笋冻（沙虫熬制冻品，配芥末酱油）、姜母鸭（炖至姜香入骨，同安金鸭子为代表）、烧肉粽（加板栗与红烧肉，蘸甜辣酱）、海鲜大排档（酱油水做法，小眼镜大排档为代表）、花生汤（黄则和，甜糯可口）。
**避坑提示**：曾厝垵、中山路主街小吃溢价高且流水线化，吃正宗闽南小吃去局口街、八市（第八市场）周边；海鲜大排档务必问清“是不是按斤算”与“加工费多少”，避免被掉包或缺斤少两；土笋冻若为透明无瑕且极便宜的多为明胶合成，真土笋冻微黄且带有沙虫鲜味。
**住宿建议**：
- **交通与美食首选**：中山路/镇海路周边（地铁1号线交汇，去鼓浪屿码头近，老字号小吃集中）。
- **海景与文艺首选**：沙坡尾/厦大/曾厝垵周边（近海与文艺区，民宿多且适合拍照，但交通稍堵）。
- **性价比与中转**：集美学村周边或厦门北站（酒店便宜，地铁进岛约40分钟，适合晚到早走）。
## 五、实用贴士与常见坑
**交通**：高崎机场离本岛极近，打车或公交31路即可到中山路；厦门站（在岛内，首选）与厦门北站（在集美，较远）均可乘地铁1号线；市内首选地铁+BRT+共享单车，环岛路务必骑行。
**核心避坑清单**：
1. **鼓浪屿船票黄牛**：船票实名制且极难抢，黄牛所谓“VIP免排队登岛”均为骗局，实为带你走普通通道或购买高价套票；务必自己在公众号抢票。
2. **出租车司机带客买茶/珍珠**：从机场、车站打车去景区，司机常以“今天朋友家茶农出售正宗大红袍/铁观音”“珍珠博物馆打折”为由绕路带去消费，拿高额回扣。务必坚决拒绝。
3. **海鲜大排档刺客**：曾厝垵、沙坡尾部分不良商家用死海鲜替换活海鲜或虚报重量，建议在开渔期去八市等本地市场自买找店加工。
4. **野导游假本地人**：鼓浪屿、厦大周边有“本地人带路50元”服务，实为带你绕远路或去特产店消费，鼓浪屿面积小且指示牌清晰，无需带路。
**特殊人群提示**：
- **亲子家庭**：除鼓浪屿外，厦门科技馆（位于文化艺术中心，互动性极强）、观音山沙滩、方特梦幻王国均为优质亲子选项；带婴儿车尽量避免登日光岩等高台阶景点。
- **老年游客**：鼓浪屿无机动车辆但上下坡多，建议穿防滑鞋；植物园有景交车但雨林世界需步行，注意地滑；环岛路风大，需带防风外套。
**气候与穿搭**：厦门属亚热带海洋性季风气候，全年温暖湿润。夏季（7-9月）极长且高温高湿，常有台风（7-9月），需关注天气停航停运信息；冬季（12-2月）温和但海风大，体感阴冷需带防风外套；春秋两季最为舒适，但紫外线强烈，去海边必须高倍防晒。全程需穿舒适防滑运动鞋，应对岛上与公园的上下坡。
