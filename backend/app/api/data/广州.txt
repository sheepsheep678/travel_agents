# 广州旅游必玩攻略
## 一、城市概览定位
广州是“花城”与“美食之都”，核心看点为**千年商埠文化、岭南建筑与西关风情、长隆亲子度假以及食在广州的餐饮体验**。最佳旅游季节为秋冬季（10月至次年3月），气候凉爽舒适且避开了雨季与台风。建议游玩时长3-5天。广州公共交通极度发达，地铁几乎覆盖所有核心景点，多数场馆免费但需提前实名预约。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（老广风情日）**：上午陈家祠 → 下午沙面岛漫步 → 傍晚永庆坊看骑楼亮灯 → 晚上恩宁路周边吃竹升面。
- **Day2（现代地标日）**：上午越秀公园看五羊石像 → 下午广东省博物馆（需提前抢票） → 傍晚花城广场看广州塔 → 晚上海心桥拍夜景。
- **Day3（亲子或购物日）**：全天长隆野生动物世界（或选择北京路步行街 + 大佛寺夜景 + 珠江夜游）。
**关键动线逻辑**：老城区（荔湾、越秀）重在历史与美食，新城区（天河、海珠）重在现代景观与大型商圈。地铁1号线与6号线串联老城区精华，3号线直通番禺长隆。住宿优选越秀区公园前或荔湾区陈家祠周边，老广味浓且去各处均近。
## 四、美食与住宿
**必吃美食**：广式早茶（虾饺、凤爪、红米肠、流沙包，代表店：点都德、广州酒家、陶陶居）、肠粉（银记、穗银、源记）、牛杂（萝卜牛杂为街头小吃之王）、云吞面（竹升面，鲜虾云吞）、烧腊（深井烧鹅、叉烧）、老火靓汤、双皮奶（南信牛奶甜品）、煲仔饭（超记、铭少）。
**避坑提示**：上下九步行街如今衰落且小吃多为外地承包流水线，不建议去吃所谓老字号；吃早茶大店早高峰排队极恐怖，务必早7点半取号或用APP提前排队；北京路周边餐饮溢价高，不如去西关老街巷觅食。
**住宿建议**：
- **文化与美食首选**：越秀区公园前/北京路周边（地铁1/2号线交汇，老广市中心，早茶老店多）。
- **交通与商务首选**：天河区珠江新城/体育西路（地铁3号线，高楼林立，去广州塔近，高端商场多）。
- **亲子度假首选**：番禺区长隆度假区周边（有免费接驳车，远离市区喧嚣，适合带娃）。
## 五、实用贴士与常见坑
**交通**：白云机场地铁3号线北延段直达市区（约40分钟）；广州南站为超大高铁枢纽，地铁2/7号线接驳，切忌搞错出发到达口；市内首选地铁与Bus Quick，支付宝“出行”申请乘车码即可。
**核心避坑清单**：
1. **广州塔登塔陷阱**：花150元排队1小时登塔看城市全貌，不如在塔下花2元走海心桥或去二沙岛免费拍全塔，出片效果更好且不折腾。
2. **上下九小吃街**：商业气息严重衰退，很多所谓老字号实为外地人承包，味道不正宗且性价比低，吃美食请去荔湾区其他街巷。
3. **出租车绕路**：广州司机多但部分拒载短途或绕路，建议用网约车平台，有行程记录更安全。
4. **买玉买药材骗局**：荔湾广场、清平中药材市场周边有“托儿”带客买高价玉器或名贵药材，切勿跟随陌生人进店消费。
**特殊人群提示**：
- **亲子家庭**：长隆度假区是绝对顶流，野生动物世界与大马戏需留足一整天；广东省博物馆适合儿童看恐龙与海洋展。
- **老年游客**：早茶慢饮是精髓，去老字号早茶店避开周末人流高峰；老城区骑楼有遮阳避雨功能，适合漫步。
**气候与穿搭**：广州属亚热带季风气候，全年长夏无冬。夏季（5-9月）极长且高温高湿，常有暴雨与台风，需常备雨具与速干衣物；春季（3-4月）有“回南天”，极度潮湿，衣物难干；秋冬季（10-2月）为最佳旅游季，凉爽舒适，早晚需薄外套，白天可短袖。
