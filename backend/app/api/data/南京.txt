# 南京旅游必玩攻略
## 一、城市概览定位
南京是“六朝古都”、“十朝都会”，核心看点为**明初皇城与明孝陵、民国风华建筑群、秦淮河畔的市井文化以及金陵美食**。最佳旅游季节为秋季（9-11月，栖霞山红叶、银杏谷最美）与春季（3-4月，鸡鸣寺樱花大道）。建议游玩时长3-4天。南京历史底蕴深厚，大部分核心景点免费但实行严格的实名预约制，特别是南京博物院和侵华日军南京大屠杀遇难同胞纪念馆，需提前一周抢票。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（钟山风物日）**：早上中山陵 → 中午音乐台喂鸽子 → 下午明孝陵神道 → 傍晚美龄宫（或回市区吃晚餐）。
- **Day2（民国历史与秦淮夜）**：早上南京博物院（或纪念馆） → 下午总统府 → 傍晚鸡鸣寺登城墙看玄武湖日落 → 晚上夫子庙秦淮河夜游。
- **Day3（郊野打卡日）**：上午牛首山文化旅游区看佛顶宫 → 下午返程逛老门东历史街区觅食。
**关键动线逻辑**：钟山风景区（中山陵、明孝陵、美龄宫）连成一片，需单独安排一整天并穿运动鞋；民国历史线（总统府、博物院、纪念馆）沿地铁2号线分布，交通极便利。住宿首选新街口或大行宫周边，为绝对市中心，地铁换乘大站。
## 四、美食与住宿
**必吃美食**：鸭血粉丝汤（小潘记、叶新小吃为代表，南京人爱吃鸭血比鸭肠多）、盐水鸭（皮白肉嫩，桂花香，韩复兴为代表）、烤鸭（南京烤鸭卤汁偏甜，与北京烤鸭完全不同）、牛肉锅贴（李记、草桥，底部酥脆汁水多）、蟹黄汤包（尹氏鸡汁汤包）、赤豆元宵、糕团小点（芳婆糕团店）。
**避坑提示**：夫子庙小吃街（如某流行美食街）溢价高且同质化严重，正宗美食在科巷、红庙、丰富路等本地人居住的街巷；南京烤鸭是斩件按斤称卖浇卤汁的，不要期待像北京烤鸭那样卷饼吃。
**住宿建议**：
- **交通与商业首选**：新街口/大行宫周边（地铁1/2/3号线交汇，中华第一商圈，去各景点均近）。
- **风景与夜游首选**：夫子庙/老门东周边（秦淮河畔，体验金陵夜泊，适合情侣，但节假日吵闹）。
- **交通枢纽中转**：南京南站周边（高铁枢纽，地铁1/3/S1号线，适合晚到早走，市区通勤稍远）。
## 五、实用贴士与常见坑
**交通**：禄口机场地铁S1号线直达南京南站（约35分钟）；南京站和南京南站均为主要高铁枢纽，南京站紧邻玄武湖，出站即可看湖景；市内地铁极其发达，覆盖所有景点，支付宝“出行”或“金陵通”乘车。
**核心避坑清单**：
1. **南博与纪念馆黄牛票**：此两处预约极难，黄牛常以“内部通道”为名收费，实为盗用个人信息批量抢票，极易导致账号被封或个人隐私泄露，务必自己定闹钟提前抢票。
2. **秦淮河野船/私导**：夫子庙周边拉客的“带你走小路看夜泊”或乘坐“私人快艇”均为骗局或极度危险，画舫必须在官方码头排队购票。
3. **钟山景区交通陷阱**：景区面积极大，内部禁停网约车，切勿全程徒步（从中山陵走到明孝陵需1小时上坡），建议购买10元不限次上下车的景区观光车票。
4. **特产伴手礼溢价**：景区周边所谓正宗盐水鸭、雨花茶多为外地代工或陈茶，建议去章云、韩复兴等老字号门店或在本地大型商超购买。
**特殊人群提示**：
- **亲子家庭**：除钟山风景区外，南京红山森林动物园（国内动物福利与互动设计天花板）、南京科技馆均为优质亲子选项。
- **老年游客**：中山陵392级台阶对老年人极不友好，可乘坐钟山风景区观光车至顶附近，或仅游览平缓的明孝陵与美龄宫；纪念馆排队久无座位，建议避开人流高峰。
**气候与穿搭**：南京属亚热带季风气候，夏季（7-8月）为中国“火炉”之一，闷热高温，体感常超40℃，需防暑；冬季（12-2月）湿冷无集中供暖，室内外温差小，需穿羽绒服；春秋两季极美但短促，秋季栖霞山赏枫需提前查红叶指数。钟山风景区与明城墙步行极多，必须穿舒适防滑运动鞋。
