# 北京旅游必玩攻略
## 一、城市概览定位
北京是六朝古都与现代首都的双重结合体，核心看点为**皇家建筑群、中轴线历史景观与胡同市井文化**，最佳旅游季节为春季（4-5月，春花初绽）与秋季（9-10月，秋高气爽、银杏红叶盛景），建议游玩时长3-5天。作为全国最严格的实名预约制城市，故宫、国家博物馆等顶流景点必须提前7天抢票，无现场售票，规划行程时务必将预约放在首位。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（中轴线皇城日）**：天安门广场（早场看升旗）→ 故宫博物院 → 景山公园登顶俯瞰 → 傍晚什刹海、南锣鼓巷漫步
- **Day2（长城与现代日）**：上午八达岭长城（缆车上下）→ 下午返程至奥林匹克公园 → 傍晚看鸟巢水立方夜景
- **Day3（祭祀与市井日）**：上午天坛公园 → 下午恭王府 → 傍晚什刹海胡同或前门大栅栏收尾
**五日深度线（家庭/慢节奏推荐）**：在三天基础上增加国家博物馆、颐和园整天、雍和宫国子监、圆明园或慕田峪长城，每日保留半天休整时间，特别适合带老人孩子的家庭。
**关键动线逻辑**：故宫与景山天然串联（神武门出即景山），天坛与前门大街顺路，长城单独安排一整天（早出发避人流），住宿优先选二环内前门、鼓楼、崇文门、东直门四大片区地铁沿线，避免昌平、顺义等远郊。
## 四、美食与住宿
**必吃美食**：北京烤鸭（果木香鸭皮蘸白糖是经典吃法，四季民福、全聚德为代表）、铜锅涮肉（清汤涮羊肉配麻酱）、老北京炸酱面、豆汁焦圈（尹三豆汁，口味挑战型小吃，酸馊味明显建议少量尝试）、卤煮、爆肚。
**避坑提示**：前门、南锣鼓巷等游客区餐饮价格偏高、品质参差，建议拐进附近胡同找本地老店；景区内物价高（故宫内一瓶水约12元），建议自带水杯和干粮。
**住宿建议**：预算充足选东城、西城二环内地铁沿线（前门、鼓楼、崇文门、东直门）；性价比优先可选海淀靠地铁地段；避开远郊区，每日通勤浪费1-2小时。
## 五、实用贴士与常见坑
**交通**：首都机场线到东直门约30分钟，大兴机场线到草桥19分钟；地铁、公交均可在支付宝"出行"申请乘车码，公交上下车都需扫码。
**核心避坑清单**：
1. **预约是铁律**：故宫、国博、天安门、恭王府、八达岭长城全部实名预约，无现场票，未约到直接进不去；所有"黄牛加价票""加急通道""内部特权票"均为诈骗。
2. **低价一日游陷阱**：天安门、前门附近"50元长城一日游"基本为购物团，正规八达岭一日游成本在280-380元/人，低于此价必有套路。
3. **免费景点门口的黄牛**：国博、军博、自然博物馆免费但常被黄牛以"约满带VIP通道"为名收取100元，切勿轻信。
4. **周一闭馆日**：故宫、恭王府周一均闭馆（法定节假日除外），规划行程避开周一安排此类景点。
**特殊人群提示**：
- **亲子家庭**：优先中国科技馆（儿童科学乐园3-8岁适用）、北京动物园海洋馆、八达岭缆车，避免纯步行景点过多。
- **老年游客**：长城选缆车直达北七楼或南四楼减少台阶，故宫走中轴线精华路线、东西六宫视体力取舍。
**气候与穿搭**：北京昼夜温差大，春秋季早晚需叠穿外套；夏季（7-8月）平均28-35℃且正午紫外线强烈，体感常超38℃，需备防晒补水用品；冬季干燥寒冷，红墙配雪景别有氛围且游客少、住宿便宜。
