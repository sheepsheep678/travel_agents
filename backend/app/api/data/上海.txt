# 上海旅游必玩攻略
## 一、城市概览定位
上海是东西方文化交融的国际大都市，核心看点为**近代外滩建筑群、现代陆家嘴天际线、弄堂石库门市井文化与迪士尼梦幻体验**。最佳旅游季节为春季（3-5月）与秋季（9-11月），气候宜人且展会较少。建议游玩时长3-5天。城市基础设施极度发达，地铁网络覆盖核心区域，但热门场馆（如上海博物馆、迪士尼）仍需提前预约或购买早鸟票。

## 三、行程规划建议
**三日经典线（首次到访首选）**
- **Day1（魔都天际线日）**：上午南京路步行街 → 下午豫园/城隍庙 → 傍晚外滩看日落与亮灯 → 轮渡过江至陆家嘴看夜景。
- **Day2（文脉与风情日）**：上午上海博物馆（人民广场馆） → 下午武康路-安福路Citywalk → 晚上静安寺周边逛夜市或酒吧。
- **Day3（梦幻或水乡日）**：全天上海迪士尼度假区（或选择朱家角古镇半日游+返程购物）。
**关键动线逻辑**：黄浦江是天然分界线，浦西（外滩、豫园、南京路、法租界）重历史与人文，浦东（陆家嘴、迪士尼）重现代与娱乐。住宿优先选人民广场、南京东路、静安寺三大地铁枢纽周边，2号线和10号线贯穿核心景点。
## 四、美食与住宿
**必吃美食**：本帮浓油赤酱代表（红烧肉、响油鳝丝、油爆虾）、生煎包（小杨生煎、大壶春，底部酥脆汤汁多）、排骨年糕、蟹壳黄、葱油拌面、白斩鸡。国际美食极其丰富，各国料理在原法租界区域均有高品质门店。
**避坑提示**：城隍庙商圈小吃溢价严重，排队极长但口味往往不如街边老店；避免在南京路步行街买高价伴手礼，真想买老字号去第一食品分店或本地超市。
**住宿建议**：
- **交通便利首选**：人民广场/南京东路周边（地铁1/2/8号线交汇），去哪都方便。
- **追求格调与夜生活**：静安寺/南京西路/新天地周边（梧桐区，酒店品质高，适合Citywalk）。
- **带娃或看江景**：陆家嘴周边（高星级酒店集中，交通稍弱但景观无敌）。
## 五、实用贴士与常见坑
**交通**：地铁网络四通八达，支付宝“出行”可申请上海乘车码；浦东机场至市区可乘磁悬浮（最高300km/h体验，单程50元，凭机票打折至40元）或地铁2号线；虹桥枢纽高铁飞机一体，地铁2/10/17号线直达。
**核心避坑清单**：
1. **外滩观光隧道**：打着观光名义实为劣质灯光秀，单程50元极不划算，过江请直接乘2元轮渡（东金线）或地铁2号线。
2. **特产伴手礼陷阱**：南京路、城隍庙所谓“老上海特产”多为外地代工，梨膏糖、花生牛扎糖品质一般，建议去国际饭店买蝴蝶酥或去本地老字号糕点铺。
3. **黄牛带路拍照**：外滩、武康大楼周边有黄牛提供“最佳机位拍照”服务，价格虚高，自己找角度即可。
4. **假酒吧/酒托**：复兴公园、武原路一带夜间有酒托拉客，切勿跟随陌生人去不知名酒吧，去正规平台推荐的门店。
**特殊人群提示**：
- **亲子家庭**：迪士尼需提前规划路线，儿童身高决定可玩项目；上海自然博物馆（静安雕塑公园内）互动性强，极适合3-12岁儿童。
- **老年游客**：避免上下高峰期挤地铁；外滩观光台无电梯需注意，轮渡有电梯可乘坐；博物馆提供轮椅租赁。
**气候与穿搭**：上海夏季梅雨季（6-7月）闷热多雨，体感不适，需带伞与防潮衣物；冬季湿冷无集中供暖，室内外温差大，需穿羽绒服；春秋季短促但最为舒适，建议叠穿应对早晚温差。
